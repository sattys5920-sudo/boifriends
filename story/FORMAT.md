# 이야기 데이터 형식 (캐릭터 하나 = 폴더 하나)

`tools/iso/story/<캐릭터id>/` 안에 파일 21개:
- `meta.json` : 짝 정보, 첫 만남, 두 갈래의 제목·결말
- `love_01.json` … `love_10.json` : 내가 사귀기 10장
- `match_01.json` … `match_10.json` : 짝 찾아주기 10장

게임 규칙(참고): 14일, 하루 4번 행동, 같은 사람과는 하루 한 번(= 하루 한 장). 처음 말을 걸면 meta.intro가 나오고 플레이어가 love/match 중 하나를 골라요. 그 뒤로는 고른 갈래의 장이 순서대로 하루 한 장씩 열려요. 10장을 다 보고, 14일째가 끝날 때 결말을 판정해요.

## 대사 한 줄
`["말하는 사람", "문장"]`
- `"c"` 이 캐릭터, `"p"` 짝(이름은 meta.pair로 표시), `"me"` 주인공(이름은 플레이어가 정함), `"n"` 지문
- 그 밖의 인물은 이름 그대로: `["진", "…"]`
- 문장 안 `{me}` 는 주인공 이름으로 바뀜. 주인공은 이름 외 성별·외모를 정하지 않음(그·그녀 쓰지 말 것)

## 장 파일 (`love_03.json` 등)
```json
{
  "route": "love", "no": 3, "title": "장 제목",
  "when": "night",                 // 선택. "night"(밤에만) 또는 생략
  "need": "score>=30",             // 선택. 조건이 안 되면 wait 대사만 나오고 장이 안 넘어감
  "wait": [["c", "…아직은 아니야."]],  // need가 있으면 필수
  "beats": [ 비트, 비트, ... ]
}
```
비트는 셋 중 하나:
1. 대사 한 줄 `["c", "…"]`
2. 선택지 `{"choice": [ {"t": "선택지 문장", "fx": {"love": 10}, "set": ["flag_name"], "then": [비트...]}, ... ]}`
   - fx 키: `love`(사귀기 점수) `match`(짝 진전 점수) `hp`(기력, -3~+2) `yen`(돈, 음수는 지출) `gift`
   - love 갈래 장에서는 love만, match 갈래 장에서는 match만 점수로 씀
   - `set`: 이후 장·결말에서 쓸 플래그(영문 소문자_숫자)
   - `then`: 그 선택 뒤에 이어지는 대사(분기). 선택지마다 다른 장면이 나와야 함
3. 조건 분기 `{"if": "flag:met_toi", "then": [비트...], "else": [비트...]}`
   - 조건: `flag:이름` / `!flag:이름` / `score>=40` / `day>=7`
   - 앞 장에서 고른 선택이 뒤 장 내용을 바꾸게 할 때 사용

## meta.json
```json
{
  "id": "curly_suit",
  "pair": "쿠루미자와 우메",
  "pairProfile": "원작·성격 요약(검색 근거)",
  "intro": { "lines": [대사...], "mode": "이 사람과는 어떻게 지내고 싶어요?" },
  "love":  { "title": "갈래 제목", "endings": [결말, ...] },
  "match": { "title": "갈래 제목", "endings": [결말, ...] },
  "after": { "love": [[대사...], [대사...]], "match": [[대사...], [대사...]] }
}
```
결말: `{"id": "true", "title": "결말 제목", "cond": ["score>=80", "flag:x"], "lines": [대사 8~20줄]}`
- 위에서부터 조건을 모두 만족하는 첫 결말이 나옴. 마지막 결말은 `"cond": []`(실패·씁쓸한 결말)
- 갈래마다 결말 3개 이상: 진(true) / 보통(good) / 나쁨(bad). 진 결말은 특정 선택(플래그)을 요구
- 10장 각 장의 선택 점수 합이 대략 최대 110~130이 되게(점수는 0~100으로 잘림). 좋은 선택 +8~15, 무난 +3~6, 나쁜 선택 -5~-10

## 분량·품질
- 장마다 대사 90~120줄(분기 안의 줄 포함), 선택지 2~3번 등장
- 원작 대사를 그대로 옮기지 말고, 설정·성격·말투만 살려 새로 쓰기(저작권)
- 큰 스포일러(작품 결말 반전)는 피하기. 폭력·범죄는 암시 수준으로, 선정적 묘사 없이
- 한국어, 캐릭터 말투 유지(반말/존댓말 일관)
- 검사: `python3 tools/iso/story_check.py <캐릭터id>` 가 OK를 출력해야 끝
