# 캐릭터별 스토리 뼈대 (초안)

각 캐릭터는 두 갈래: **사귀기**(주인공과) / **짝 찾아주기**(짝과 이어 주기). 갈래당 10장 기준.
흐름은 「1~2장 → 3~4장 → 5~6장 → 7~8장 → 9~10장」. 결말은 진 / 보통 / 나쁨.

## 주인공
- 한국(서울)에 사는 30대 초반 여성, 게임 회사 시나리오 라이터. 이름은 플레이어가 정함({me}).
- 출장·취재·콜라보 등으로 도쿄와 도와 왕국을 드나든다. 사람을 관찰하고 대사를 받아 적는 직업 습관이 이야기의 열쇠.
- 사귀기 갈래의 공통 갈등: 마감과 출장 기한, 서울과의 거리, '쓸 것인가 / 지킬 것인가'.
- 원작에서 미성년인 캐릭터(슌·카나토·마코토·히데오·쿈·쿠스오·노자키)는 **사귀기 갈래에서만** 20대 중반 이상 성인이 된 시점으로 등장한다. 짝 찾아주기 갈래는 원작 나이 그대로.

---

## 1. 쿠지 치카이 (사라잔마이) · 아사쿠사 강변 — 짝: 쿠루미자와 우메
**사귀기 「쓰지 않는 이야기」** 아사쿠사 배경 게임을 취재하러 출장 온 {me}가 밤 강변에서 메모를 하다 치카이의 거래를 목격한다. "그 수첩, 이리 줘." 작가의 습관이 위험을 부르고, 치카이는 그녀를 지키려 곁에 붙어 다니게 된다.
흐름: 취재 메모를 빼앗기며 첫 만남 → 입단속 겸 '관광 가이드'가 된 치카이, 소바집 골목 안내 → 그녀가 쓴 대사를 치카이가 몰래 읽고 "이거 나네" → 동생 토이를 지켜보는 형의 얼굴을 보고 쓰고 싶어지지만 참는 그녀 → 마지막 거래 밤, '쓸 것인가, 곁에 남을 것인가'.
결말: 진 = 원고 대신 그를 택해 출장을 연장 / 보통 = 한국으로 돌아가 이름을 바꾼 캐릭터로 그를 남김 / 나쁨 = 수첩만 돌려받고 그는 사라짐.

**짝 찾아주기 「잔소리와 당고」** 상경해 당고 노점에서 일하는 우메가 담배·끼니를 두고 치카이에게 잔소리를 퍼붓고, 주인공이 둘 사이를 잇는다.
흐름: 노점의 우메가 "그 정장 아저씨 밥은 먹어요?" → 주먹밥 배달 → 우메의 계산적이던 과거와 솔직해지려는 지금 → 비 오는 날 우산 → 치카이가 직접 노점으로.
결말: 진 = "잔소리 평생 해 줘" / 보통 = 단골과 아르바이트생 사이 / 나쁨 = 치카이가 우메를 위해 거리를 둠.

## 2. 니노 (ACCA 13구 감찰과) · 도와 분수 광장 — 짝: 시노미야 카구야
**사귀기 「관찰자 둘」** 국제 열차를 타고 도와 왕국으로 배경 로케 헌팅을 온 {me}. 사람을 '관찰'하는 게 직업인 그녀와, 친구를 늘 지켜보는 니노는 서로를 금방 알아본다.
흐름: 왕궁 광장에서 서로 스케치·사진을 찍다 마주침 → 니노가 바동 구석구석을 안내, 진의 바에 합석 → 그녀의 캐릭터 노트에 니노가 들어가고 니노는 그걸 눈치챔 → 니노가 숨긴 일의 기미에 그녀가 '설정 구멍'처럼 파고듦 → 선글라스를 벗고 "이번엔 내가 보이는 쪽이 될게".
결말: 진 = 서울과 바동을 오가는 관계 / 보통 = 진의 바에서만 만나는 술친구 / 나쁨 = "쓰지 마. 날 쓰면 위험해"라며 멀어짐.

**짝 찾아주기 「고백은 누가 먼저」** 가문 일로 도와 왕국을 찾은 카구야. 상대가 먼저 고백하게 만드는 두뇌전 기질의 카구야와, 느긋하게 다 꿰뚫어 보는 니노가 서로 '먼저 말하게' 하려는 신경전.
흐름: 왕궁 연회장에서 만남 → 카구야의 작전, 니노의 무심한 간파 → 주인공이 양쪽 작전 참모 → 카구야가 서툰 진심을 드러내는 사건 → 누가 먼저 말하나.
결말: 진 = 동시에 말해 버림 / 보통 = "다음 판에서 결판" / 나쁨 = 둘 다 끝까지 안 말함.

## 3. 후타미 슌 (쿨도지 남자) · 학교 — 짝: 아리마 카나
**사귀기 「일부러 아니에요」** (성인 시점: 실업팀 핸드볼 선수 26세) 스포츠 게임 감수를 맡아 연습장을 찾은 {me}. 잘생긴 에이스는 실수할 때마다 "일부러예요"라며 우긴다.
흐름: 모션 촬영 중 넘어진 슌 "일부러" → 그의 허세를 대사로 쓰자 질색 → 누나의 카페에서 '귀엽다' 소동 → 시합 패배 뒤 처음으로 허세 없는 얼굴 → 그녀의 귀국 전날 솔직한 고백.
결말: 진 = "일부러 아니고, 진심이에요" / 보통 = 게임 속 캐릭터 모델로 남는 인연 / 나쁨 = 끝까지 허세로 보내 버림.

**짝 찾아주기 「NG는 한 번만」** 학교 근처 촬영으로 온 배우 카나. 허세 부리는 슌의 실수를 카나가 프로의 눈으로 다 짚어 내며 티격태격.
흐름: 촬영 엑스트라로 슌 섭외 → NG 연발, '일부러였다' → 카나의 직설과 은근한 챙김 → 카나의 슬럼프를 슌이 우직하게 응원 → 한 번에 오케이 난 장면.
결말: 진 = 둘이 같은 화면에 / 보통 = 서로의 시합·무대를 보러 가는 사이 / 나쁨 = 슌의 허세에 카나가 질려 버림.

## 4. 타나카 요이치 (아오하라이드) · 학교 — 짝: 후지오카 하루히
(주인공은 성인: 학교 근처 카페 직원 등)
**사귀기 「동갑의 퇴근길」** 학원물 게임 취재로 학교 방문 허가를 받은 {me}. 같은 30대 초반인 요이치와 '어른의 고단함'을 나누는 이야기.
흐름: 교무실 견학 → 퇴근길 이자카야에서 한국 학교·일본 학교 이야기 → 동생 코우 걱정을 털어놓는 요이치 → 그녀의 마감 지옥을 그가 챙김 → 서울 귀국 날짜가 다가오는 주말.
결말: 진 = 방학마다 서울에 오겠다는 약속 / 보통 = 랜선 퇴근길 통화 친구 / 나쁨 = 웃는 얼굴로 "좋은 여행이었어요".

**짝 찾아주기 「무심한 사람과 웃는 사람」** 오란 고교 호스트부를 졸업하고 법학부에 진학한 대학생 하루히(성인)가 교육 봉사로 학교에 온다. 둔감하고 직설적인 하루히가 요이치의 웃음 뒤를 아무렇지 않게 꿰뚫는다. 호스트부 시절 이야기(손님 접대, 부원들의 소동, 갑자기 들이닥치는 옛 부원들)를 회상과 대사로 곳곳에 넣는다.
흐름: 봉사 첫날, 학생들이 하루히의 '접대 미소'에 술렁임 → 하루히의 "선생님 웃는 거 피곤해 보여요" → 마트 특가·서민 감각으로 의기투합, 호스트부 시절 회상 → 옛 부원들의 소란스러운 방문으로 요이치가 하루히의 과거를 알게 됨 → 하루히의 목표(법조인)를 요이치가 응원, 봉사 마지막 날.
결말: 진 = 둘이 같이 장 보는 주말 / 보통 = 서로의 상담 상대 / 나쁨 = 바쁜 일정 속에 연락이 끊김.

## 5. 혼죠 렌 (NANA) · 시부야 골목 — 짝: 이치하라 유코
**사귀기 「콜라보 곡」** 리듬 게임 콜라보로 렌에게 곡을 의뢰한 회사, 곡에 붙일 이야기를 쓰는 {me}. 말수 적은 기타리스트와 말로 먹고사는 작가.
흐름: 녹음실 첫 미팅, 대답이 "…응"뿐 → 시부야 골목 라멘집에서 곡의 장면을 묻는 그녀 → 버려진 항구 이야기를 처음 꺼내는 렌 → 투어와 마감이 겹친 밤 → 완성된 곡의 첫 관객.
결말: 진 = "이 곡, 너한테 쓴 거야" / 보통 = 다음 콜라보도 같이 / 나쁨 = 곡만 남고 투어로 떠남.

**짝 찾아주기 「소원의 대가」** 어느 밤 시부야 뒷골목에 나타난 수상한 가게의 주인 유코. 렌이 소원을 빌고, 그 '대가'를 치르는 과정에서 둘이 엮인다.
흐름: 길을 잃다 가게 발견 → 렌의 소원(잃어버린 소리) → 대가로 술 상대·곡 한 곡 → 유코의 장난과 깊은 통찰 → 소원이 이뤄지는 밤.
결말: 진 = "우연이 아니었네" / 보통 = 가끔 술 마시러 가는 단골 / 나쁨 = 가게가 다시는 보이지 않음.

## 6. 우고 카나토 (얼굴만으로는 좋아하지 않아요) · 긴자 — 짝: 미야자와 유키노
**사귀기 「목소리로」** (성인 시점: 20대 중반, 얼굴 때문에 배우 제안만 받는 청년) 게임 캐릭터 성우 오디션에 몰래 지원한 카나토. 블라인드 심사에서 그의 '목소리'를 고른 사람이 {me}였다.
흐름: 오디션장에서 얼굴을 보고 굳는 카나토 "역시 얼굴 보고 뽑았죠" → "블라인드였는데요?" → 녹음 디렉션으로 쌓이는 신뢰, 꼬인 자의식 폭발 → 갑자기 다정해지는 갭 → 출시일, 얼굴 없이 이름만 크레딧에.
결말: 진 = "얼굴 말고 날 봐 준 사람" / 보통 = 단골 성우와 작가 / 나쁨 = 얼굴이 알려지자 사라짐.

**짝 찾아주기 「가면 둘」** 완벽한 우등생을 연기하던 유키노와, 잘생긴 얼굴로만 보이던 카나토. 서로의 가면을 단번에 알아보는 두 사람.
흐름: 긴자 카페에서 공부하는 유키노 → 서로 '연기'를 눈치챔 → 가면 벗은 모습을 처음 보여 줌 → 주변 기대에 다시 갇히는 위기 → 있는 그대로의 데이트.
결말: 진 = 둘 다 맨얼굴로 웃음 / 보통 = 서로의 비밀 공유자 / 나쁨 = 다시 가면 속으로.

## 7. 쿠노우 토토노우 (미스터리라 하지 말지어다) · 롯폰기 미술관 — 짝: 잔느
**사귀기 「플롯 구멍」** 미스터리 게임 시나리오 자문을 구하러 롯폰기 미술관 앞에서 토토노우를 만난 {me}. 그는 그녀의 트릭을 한 장씩 담담하게 무너뜨린다.
흐름: "저는 늘 생각하는데요, 이 범인은 이렇게 안 해요" → 매주 원고 첨삭과 카레 → 한국 음식과 카레 교환 → 그녀의 '당연한 설정'에 그가 의문을 던지며 그녀 자신에 대한 이야기로 → 탈고한 원고 마지막 페이지의 헌사.
결말: 진 = 공동 작가로 이름을 올림 / 보통 = 평생 원고를 봐 주는 독자 / 나쁨 = 지론이 상처가 되어 원고를 접음.

**짝 찾아주기 「괴물과 사람 사이」** 미술관 '흡혈귀 전시'에 나타난 수수께끼의 소녀 잔느. 정의와 경계에 대해 끝없이 묻는 토토노우와, 정체를 숨긴 잔느.
흐름: 전시실의 소녀 → 토토노우의 질문 공세에 당황하는 잔느 → 단 것을 좋아하는 잔느와 카레 → 잔느의 정체가 드러날 위기 → "괴물인지 아닌지는 당신이 정하는 게 아니에요".
결말: 진 = 서로를 있는 그대로 / 보통 = 편지를 주고받는 사이 / 나쁨 = 잔느가 떠남.

## 8. 헤이와지마 시즈오 (듀라라라!!) · 이케부쿠로 — 짝: 키타가와 마린
**사귀기 「무섭지 않은 사람」** 이케부쿠로 도시 전설 게임 로케 중 자판기가 날아오는 걸 목격한 {me}. 도망치는 대신 "괜찮아요?"라고 물은 첫 사람.
흐름: 날아간 자판기 옆에서 첫 만남 → 우유와 푸딩으로 친해짐, 톰 선배의 놀림 → 그녀가 '최강의 남자' 설정 취재를 하다 이자야의 장난에 휘말림 → 화를 참고 그녀를 지킨 날 → 한국에 오면 자판기는 안 던지겠다는 약속.
결말: 진 = "너 앞에선 화가 안 나" / 보통 = 국제 우유 친구 / 나쁨 = 휘말리지 말라며 밀어냄.

**짝 찾아주기 「코스어 아니에요」** 바텐더 차림의 시즈오를 코스어로 착각한 마린. 전혀 무서워하지 않는 마린에게 시즈오가 당황한다.
흐름: 애니 굿즈 거리에서 "사진 찍어도 돼요?" → 마린의 '좋아하는 것' 이야기 → 옷 수선(동생이 준 옷) → 행사장 소동, 시즈오가 지킴 → 마린의 코스 촬영에 같이.
결말: 진 = "있는 그대로 멋있어요" / 보통 = 촬영 담당 / 나쁨 = 소동이 커져 마린이 다침을 걱정해 멀어짐.

## 9. 쿄고쿠 마코토 (명탐정 코난) · 시골 신사 — 짝: 스즈키 소노코

**짝 찾아주기 「졸린 소녀와 늑대」** 늘 졸린 마녀 네무와, 서브컬처 덕후 케이고. 네무의 숨은 취미(마이너 문화)를 케이고가 알아보며 가까워진다.
흐름: 교실에서 꾸벅꾸벅 조는 네무 → 둘 다 같은 마이너 작품의 팬임을 알게 됨 → 네무의 비밀(겉과 다른 취향)을 케이고가 지켜 줌 → 초승달 밤의 소동에서 네무가 울프를 마주함 → 둘만의 오프라인 이벤트.
결말: 진 = "너랑은 메이저도 같이 듣고 싶어" / 보통 = 덕질 동지 / 나쁨 = 서로 비밀을 지키느라 거리가 생김.

## 20. 사카타 긴토키 (은혼) · 아사쿠사 — 짝: 츠쿠요
**사귀기 「만사해결사 의뢰서」** 시대극 게임 자료 조사 중 사기를 당한 {me}가 아사쿠사에서 '뭐든 해결해 준다'는 간판을 본다.
흐름: 보수는 파르페로 계약 → 고양이 찾기, 이사 도우미 등 엉뚱한 의뢰를 함께 → 그녀가 사기꾼에게 다시 휘말리자 목검을 든 긴토키 → 월세 대신 그녀의 원고를 지켜 준 밤 → "의뢰 아니어도 와도 돼".
결말: 진 = 만사해결사 직원 등록 / 보통 = 단골 의뢰인 / 나쁨 = "평범하게 살아"라며 밀어냄.

**짝 찾아주기 「지하의 태양」** 요시와라의 수호자 츠쿠요. 술만 마시면 난폭해지고 연애엔 서툰 그녀와, 아무렇지 않게 곁에 있는 긴토키.
흐름: 츠쿠요의 순찰에 긴토키가 끌려옴 → 술자리 대참사 → 츠쿠요의 '여자는 버렸다'는 각오에 주인공이 의문을 던짐 → 위기에서 서로의 등을 맡김 → 츠쿠요가 처음 꾸민 날.
결말: 진 = 긴토키의 "그 얼굴, 나쁘지 않네" / 보통 = 술친구이자 전우 / 나쁨 = 츠쿠요가 마음을 접음.

## 21. 니후지 히로타카 (오타쿠에게 사랑은 어려워) · 긴자 — 짝: 모모세 나루미
**사귀기 「협동 플레이」** 게임 회사 시나리오 라이터 {me}와, 같은 업계 거래처의 무표정한 하드코어 게이머.

결말: 진 = 같은 게임기를 나눠 쓰는 사이 / 보통 = 최강의 듀오 / 나쁨 = 게임 밖에서 말을 잇지 못함.

**짝 찾아주기 「오타쿠 숨기기 실패」** 회사에선 덕질을 숨기는 나루미와, 숨길 생각이 없는 소꿉친구 니후지.

결말: 진 = 니후지의 서툰 진짜 고백 / 보통 = 편한 연인 / 나쁨 = 취미 때문에 다툼.

## 22. 우스이 타쿠미 (회장님은 메이드 사마!) · 하라주쿠 — 짝: 아유자와 미사키

결말: 진 = 미사키의 "변태 외계인… 좋아해" / 보통 = 티격태격 라이벌 / 나쁨 = 미사키가 비밀이 들킬까 우스이를 밀어냄.

## 23. 이즈미 리오 (만월을 찾아서) · 시부야 — 짝: 메로코 유이
