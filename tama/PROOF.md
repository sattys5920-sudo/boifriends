# 대사 교정 지침

대상 파일(캐릭터마다 2개): /home/user/boifriends/tama/dialogue/<id>.json, /home/user/boifriends/tama/mumble/<id>.json
- 문자열 값만 고친다. JSON 구조·키·배열 개수·줄 수는 절대 바꾸지 않는다. "{call}" 자리표시자는 그대로 둔다.
- 국립국어원 표준국어대사전과 한글 맞춤법 기준으로 띄어쓰기·맞춤법을 고친다.
  예: 의존 명사 띄어 쓰기(할 수, 먹을 거, 한 번, 줄 거야, 그런 거), 보조 용언, '안/않', '돼/되', '-ㄹ게', '몇 시', '못하다/못 하다', '안 되다/안되다' 등.
- 숫자 뒤의 단위·명사는 모두 띄어 쓴다: "3페이지"→"3 페이지", "5개비"→"5 개비", "100코인"→"100 코인", "10시"→"10 시". 단 "%" 기호는 숫자에 붙인다.
- 말투(반말/존댓말, 원작 말버릇, 구어체 어미 '-냐', '-잖아', '-거든')와 내용, 길이는 바꾸지 않는다. 일부러 쓴 구어 표현(예: "몰라~")은 유지하되 명백한 오타·비표준 표기만 고친다.
- 말줄임표(…, ……, ...)는 손대지 말 것. (나중에 일괄 변환)
- 사이키 줄의 괄호 ( )는 유지.
수정 후 python3 -c "import json;json.load(open(PATH))" 로 각 파일이 유효한지 확인.
